# Glossario di dominio — Tesoreria e Cash Management

| Termine | Significato |
|---------|-------------|
| CBI | Corporate Banking Interbancario — standard italiano per flussi bancari |
| SEPA | Single Euro Payments Area — area unica dei pagamenti in euro |
| SCT | SEPA Credit Transfer — bonifico SEPA |
| SDD | SEPA Direct Debit — addebito diretto SEPA |
| pain.001 | XML SEPA per disposizioni di bonifico (Customer Credit Transfer Initiation) |
| pain.008 | XML SEPA per disposizioni SDD (Customer Direct Debit Initiation) |
| camt.052 | XML SEPA per estratto conto infragiornaliero (Bank to Customer Account Report) |
| camt.053 | XML SEPA per estratto conto fine giornata (Bank to Customer Statement) |
| camt.054 | XML SEPA per notifica di accredito/addebito (Bank to Customer Debit Credit Notification) |
| RiBa | Ricevuta Bancaria — strumento di pagamento italiano |
| MAV | Pagamento Mediante Avviso — bollettino bancario |
| F24 | Modello di pagamento unificato per tributi e contributi |
| PSD2 | Payment Services Directive 2 — direttiva UE per Open Banking |
| AISP | Account Information Service Provider — accesso in lettura ai conti |
| PISP | Payment Initiation Service Provider — disposizione pagamenti |
| Open Banking | Accesso a dati bancari tramite API standardizzate (PSD2) |
| Cash Pooling | Gestione centralizzata della liquidità di più conti/società |
| Riconciliazione | Processo di matching tra movimenti bancari e registrazioni contabili |
| Partita aperta | Registrazione contabile non ancora riconciliata con il movimento bancario |
| Disposizione | Ordine di pagamento (bonifico, RiBa, SDD, F24) |
| Cash flow previsionale | Stima dei flussi di cassa futuri basata su scadenze e pattern |
